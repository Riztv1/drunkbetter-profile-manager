Hardware y protocolo: desarrollado mediante ingeniería inversa sobre DrunkDeer A75 Pro (VID 1452 / PID 591). No se garantiza compatibilidad con otros modelos ni con futuras actualizaciones de firmware. Ante cualquier desajuste, puedes restablecer el teclado desde el software o web oficial.
